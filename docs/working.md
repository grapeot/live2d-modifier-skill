## Lessons Learned
- 透明贴图缩小不能先做 8-bit 预乘再还原；低 alpha 区的量化误差会放大为叠层色差。浮点处理后仍需近景验收，不能以全身缩略图替代。
- 恢复硬隐藏网格后须复查默认外观；共享 UV 的左右渐变可能互相覆盖。并行交接先固定版本与测试边界，再合并增量，避免覆盖另一任务的配饰或把晚到版本混入交付。
- 渐变和印花需要保留图像编辑后的 UV 残差回填，不能缩成单纯色相调整。
- 新增贴图页必须同时检查引用名与磁盘路径占用（包括悬空软链接），并拒绝覆盖创建；仅在复制模型时保护源目录不足以保证源贴图不被修改。
- 缓存键必须包含纹理尺寸、UV、三角拓扑、绘制顺序与可见性；共享 UV 检查要覆盖所有网格对，不能只记录最后一个占用者。
