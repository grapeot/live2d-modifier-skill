# 测试与验收方案（Test Plan）：live2d-modifier-skill

## 1. 测试状态说明

`live2d-modifier-skill` 的核心算法与 13 个命令接口已在本地私有原型中通过真实 Live2D 模型实验验证。

本仓库作为剥离全部私有资产后的公开版本，其打包形态、无模型单测套件与独立 Agent 端到端流程目前处于**待验收状态**。在下列测试全部执行并记录结果前，任何文档均不得宣称公开版测试已通过。

## 2. 测试分层策略

为兼顾开源仓库的合规要求（零模型资产、零专有 SDK 入库、零付费 API 依赖）与真实生产可用性，测试分为两层：

1. **第一层：公开 CI 无模型 Synthetic 测试（仓库内自动化）**
2. **第二层：外部私有工作区真实模型 E2E 验收（仓库外独立 Agent 盲测）**

---

## 3. 第一层：公开 CI 无模型 Synthetic 测试

### 3.1 运行约束

- **禁止外部模型**：`tests/` 目录下不存放任何 `.moc3` 原件、真实贴图、渲染截图、真实部件名或角色配方。
- **禁止付费与外部网络调用**：CI 全程离线运行，不调用任何图像生成 API。
- **纯代码合成 Fixture**：所有测试输入（模拟 UV 三角网格、合成贴图页、模拟屏幕-UV 映射缓冲、合成原图与重绘图、最小二进制结构桩）均由测试代码在内存中或临时目录动态生成。

### 3.2 测试覆盖清单

1. **部件级色彩映射测试（`test_color_mapping.py`）**
   - 构造带明暗梯度的合成部件贴图与经过非线性调色/加渐变的合成目标图。
   - 验证阶段一颜色映射拟合后，未出现在屏幕可见区的遮挡 UV 像素是否获得与可见区一致的平滑底色，且无通道溢出。
2. **UV 残差反投影与多视角融合测试（`test_residual_projection.py`）**
   - 使用已知重心坐标与 UV 映射的合成三角网格，在屏幕空间注入空间渐变与几何图案。
   - 验证反投影后的贴图残差位置精度、边缘羽化连续性，以及全身低分辨率与头部高分辨率双视口输入下近景高权重覆盖是否正确。
3. **`overrides` 与 `residual_holes` 行为测试（`test_overrides_and_holes.py`）**
   - 验证半透明/正片叠底/镜像 UV 网格在配置 `overrides` 后是否正确跳过残差或锁定指定映射。
   - 在两个独立平移动画网格交界处构造跨缝图案，验证启用 `residual_holes` 后交界区域是否完整清除残差并恢复阶段一基础底色。
4. **贴图冲突检测与拆页测试（`test_conflicts_and_page.py`）**
   - 构造两个共用同一 UV 矩形的合成网格（模拟署名网格与衣服网格共用贴图）。
   - 验证 `conflicts` 准确检出重叠对，且拆页操作后两网格分别指向不同贴图页、修改其中一页不影响另一页。
5. **像素微调与 CLI 参数契约测试（`test_texels_and_cli.py`）**
   - 验证 `texels` 对指定矩形区域的确定性读写与幂等性。
   - 验证 `l2d-mod` 全部 13 个子命令（`inventory`、`render`、`sheet`、`capture`、`pick`、`conflicts`、`transfer`、`variant`、`texels`、`page`、`moc check`、`vts`、`serve`）的 `--help` 与参数解析正常工作。

## 4. 第二层：外部私有工作区真实模型 E2E 验收

### 4.1 隔离与执行规则

- **物理隔离**：测试在仓库外的私有工作目录执行，使用合法取得的自有 Live2D 模型与本地放置的 `live2dcubismcore.min.js`。测试产物、日志与截图均留在外部私有目录，严禁拷入公开仓库。
- **独立 Agent 盲测**：启动一个未参与本项目开发的独立 AI Agent 会话，仅向其提供公开版 `skills/live2d-modifier/SKILL.md`、本地安装的 `l2d-mod` CLI、源模型路径、一段新的风格描述（或参考图）及外部输出目录。

### 4.2 五项端到端验收标准

独立 Agent 完成改款后，逐项核查以下五条标准：

1. **模型加载与二进制完整性（Load & Integrity）**
   - 对输出目录运行 `uv run l2d-mod moc check <output_model_dir>` 返回零错误。
   - 输出模型可在 Playwright 渲染器（`render` / `serve`）及 VTube Studio 中正常加载，无缺失贴图、非法参数索引或崩溃。
   - 原模型目录所有文件的哈希值保持不变；若执行 `vts` 安装，确认生成的模型目录名、显示名与 `ModelID` 均为新值，未覆盖原模型。
2. **多姿态与运动检查（Motion & Seam Verification）**
   - 渲染并检查全部标准动作与表情：`front`、`blink`、`talk`、`smile`、`turn_l`、`turn_r`、`look_up`、`sway`，同时输出全身与头部近景对比图。
   - 重点检查闭眼眼皮、张嘴唇周、大角度转头脸颊与发丝交界、身体摆动时衣摆与配饰边缘：不得出现遮挡处露出原模型旧底色，也不得出现跨独立运动网格的图案撕裂或错位。
3. **贴图解耦与局部保留（Conflict Isolation）**
   - 若测试模型包含画师署名网格或指定保留原貌的部件，核验其贴图区域在 `conflicts` 拆页后保持原样，未受相邻服装重绘污染。
4. **视觉质量（Visual Quality）**
   - 新配色、空间渐变与表面纹样符合给定的风格描述或参考图要求，面部妆容与五官线条清晰，半透明与正片叠底阴影层过渡自然。
5. **管线可重放性（Reproducibility）**
   - 保留外部工作目录中的 `variant` 配置、重绘后的渲染图、`transfer` 配置与 `texels` 脚本，在干净输出目录重跑命令链，生成的贴图与模型结构与首次运行一致。
